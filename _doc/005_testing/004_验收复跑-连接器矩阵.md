# 验收复跑 · 连接器矩阵（输入类型 / 输出类型）

> 卡面纪律：**不引任何 MQ / POI / HTTP 客户端第三方依赖**（镜像体积 + 版本耦合不划算）。
> 文件与 Excel 用 JDK 自带能力（`java.nio` / `java.util.zip` + StAX），HTTP 用 JDK 自带
> `java.net.http.HttpClient`，消息走 `MessageBus` SPI（宿主注入 Kafka/RocketMQ，不注入就用落库队列）。
> 全部验收在**本地 H2 + 临时目录 + 本地 HTTP 服务**上跑，**不连任何真实库 / 生产库 / 外网**。

---

## 1. 输入类型（源）

| 类型串 | 干什么 | 关键 config | 增量口径 |
|---|---|---|---|
| `jdbc.source` | 分页游标拉库 | `table/columns/where/pageSize/eventTimeColumn/resume` | 复合游标（SQL 侧过滤） |
| `file.csv.source` | 读 CSV 文件 | `path/delimiter/quote/header/encoding/columns/columnTypes/skipRows/limit` | 事件时间游标 / `__offset__` 行号游标 |
| `file.json.source` | 读 JSON 文件（NDJSON / 数组） | `path/format/itemPath/columns/columnTypes` | 同上 |
| `file.xlsx.source` | 读 Excel 首张表（零依赖） | `path/sheet/header/columns/columnTypes` | 同上 |
| `http.source` | 拉 REST / JSON 接口 | `url/method/headers/body/itemPath/pageParam/maxPages/allowedHosts` | 同上 |
| `inline.source` | 声明里的静态行 | `rows/columnTypes` | — |
| `script.source` | 沙箱脚本生成数据 | `script/engine/name/timeoutMs/maxOutputChars` | — |
| `message.source` | 从消息总线消费 | `topic/pollSize` | 消费即标记 |

## 2. 输出类型（汇）

| 类型串 | 干什么 | 关键 config |
|---|---|---|
| `jdbc.sink` | 批量 upsert / insert（幂等键） | `table/batchSize/writeMode/columns/idempotencyKey` |
| `file.csv.sink` | 写 CSV（表头 + 列顺序 + 追加） | `path/columns/delimiter/quote/encoding/append` |
| `file.json.sink` | 写 JSON（`ndjson` / `json` 数组） | `path/format/columns/encoding/append` |
| `http.sink` | POST 到外部接口 | `url/method/headers/format(json\|form)/timeoutMs` |
| `message.sink` | 发到消息总线 | `topic/keyColumn/keyField/format(json\|text)` |
| `console.sink` | 打日志（调试） | — |
| `collect.sink` | 收进内存（测试 / 预览） | — |

## 3. 架构口径

- 所有源实现 `PullSource`（拉一条 + 报水位 + 报游标）⇒ 执行器换输入类型零改动。
- 所有汇实现 `CountingSink`（报写了多少行）⇒ 执行器换输出类型零改动。
- 增量过滤口径与 JDBC 源**完全一致**：`(w > ?) OR (w = ? AND tb > ?)`（见 `WatermarkCursor`）。
- 类型串别名：`csv.source` / `json.source` / `excel.source` / `rest.source` / `kafka.source` /
  `kafka.sink` / `webhook.sink` / `mq.source` / `mq.sink` 等。

## 4. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=ConnectorTypesTest
```

预期：`Tests run: 11, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `inlineSourceFeedsStream` | 内联常量源 |
| `csvSourceReadsFileAndResumesByWatermark` | CSV 源 + 类型归一 + **第二轮只搬增量** |
| `jsonSourceReadsNdjsonAndArray` | NDJSON + JSON 数组（`itemPath`） |
| `xlsxSourceReadsWorkbook` | Excel 首张表（内联字符串 + 数值） |
| `httpSourceFetchesJson` | HTTP 源 + `itemPath` + `allowedHosts` 校验 |
| `scriptSourceGeneratesRows` | 脚本源（GROOVY 沙箱） |
| `messageSourceConsumesPublishedMessages` | 消息发 → 消息收（库表队列） |
| `csvSinkWritesFile` | CSV 汇（表头 + 列顺序） |
| `jsonSinkWritesFile` | JSON 汇（两种形态） |
| `httpSinkPostsRows` | HTTP 汇（POST JSON） |
| `typeAliasesResolve` | 类型别名解析 |
