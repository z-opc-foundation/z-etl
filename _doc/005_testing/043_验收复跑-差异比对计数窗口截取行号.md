## 口径备注

- `diff` 产出顺序 = 左流首现序（INSERT/UPDATE/SAME）→ 右流首现序（DELETE）；
  UPDATE 发**左行**（当前值）、DELETE 发**右行**（基线值）；数值统一 BigDecimal 比对（类型漂移不误报 UPDATE）。
- `diff` 与 `join` 同一套双入边校验（正好两条入边 + `left`/`right` 指名到位）。
- 计数窗口的 `windowStart`/`windowEnd` 是**记录条数区间**（不是毫秒）；产出行无事件时间
  （count 口径不参与下游事件时间运算）。
- 计数窗口按键计数器随检查点持久（`counters` 状态）⇒ 断点续跑编号不断档。
- `limit` / `index` 都是无状态（进程内计数，不进检查点）——重跑从头计数，与「到达序」口径自洽。
