# 验收复跑 · 管道参数（`${name}` 占位符）

> 卡面纪律：**缺参数不糊过去**（空串会让 `WHERE` 变恒真 ⇒ 增量悄悄变全量）；**参数值过白名单**（拼进 SQL 不成注入面）。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | 占位符写法 `${name}`（名字限字母数字与下划线） | 名字不进 SQL，只做取值键 |
| 2 | 内置参数 `bizdate`（今天）/ `yesterday`（昨天）/ `now` | 日批作业的默认口径；显式传入的同名参数优先 |
| 3 | **缺参数直接报错** | 空串会让 `WHERE` 变恒真 ⇒ 增量悄悄变全量（隐性数据事故） |
| 4 | **参数值过白名单** `[A-Za-z0-9_.:/+\\-=]{0,200}` | 无引号 / 分号 / 空格 ⇒ 拼进 `where` / `orderBy` 也不是注入面 |
| 5 | 落库的定义**保留占位符** | 一份模板天天跑不同批次；参数只作用于本次运行 |
| 6 | 流水线名**不支持**占位符 | 名字是水位 / 状态快照的键，改名等于换一条管道 |
| 7 | 替换范围：节点 config 的**全部字符串**（含嵌套 map / list） | `where` / `table` / `path` / `pushdown.filter` / `mappings` 都能参数化 |

## 2. 三个入口

| 入口 | 用法 |
|---|---|
| Web | `POST /api/etl/pipelines/{name}/run` body `{"bizdate": "2026-11-19"}` |
| 代码 | `engine.run(name, params)` / `PipelineParser.parse(text, params)` |
| 直接解析文本 | `PipelineParams.resolveText(text, params)` |

## 3. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=PipelineParamsTest
```

预期：`Tests run: 8, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `substitutesPlaceholdersInConfig` | 节点配置里的 `${name}` 换成传入值（表名 / where） |
| `builtinsAreAvailable` | 内置参数 `bizdate` / `yesterday` / `now` 不传也能用 |
| `missingParamFails` | 缺参数直接报错并点名缺哪个 |
| `unsafeValueRejected` | 带引号 / 分号的参数值直接拒（拼进 SQL 就是注入面） |
| `substitutesNestedValues` | 嵌套结构（`pushdown.filter` / `mappings` 列表）里的占位符也替换 |
| `storedDefinitionKeepsPlaceholders` | 落库的定义保留占位符；同一条流水线按不同参数跑出不同行数 |
| `rejectsPlaceholderInName` | 流水线名带占位符直接拒 |
| `resolvedSpecStillRuns` | 参数化后照常跑（内联行里的占位符也被替换） |
