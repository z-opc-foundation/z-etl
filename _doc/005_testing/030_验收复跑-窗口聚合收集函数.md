# 030 验收复跑 —— 窗口聚合收集函数

## 口径

1. `window.aggregate` 里 `COLLECT_LIST` / `COLLECT_SET` 照常工作（与 `aggregate` 共用 Accumulator，本档验收的是**事件时间窗口 + 水位触发**的完整链路）。
2. 窗口触发时产出**当时快照**：窗口内收到的值收成数组，两个窗口各一份，互不串。
3. `COLLECT_SET` 同窗口同值只收一次、保持插入序。
4. 与 `SUM(amount)` / `COUNT(*)` 同声明互不干扰。
5. 注意：`SUM("*")` 不是计数（`*` 只对 `COUNT` 有意义）—— 计数用 `COUNT(*)`。

## 用例

| 用例 | 输入（t 毫秒） | 断言 |
| --- | --- | --- |
| windowCollectList | 100:a、150:b、210:c，窗口 100ms | 两窗口各产出：[a,b] 与 [c]；COUNT(*) = 2 / 1 |
| windowCollectSet | 100:a/10、120:a/20、140:b/30 | tags = [a,b]（去重插入序）；SUM = 60 |

全量：`mvn -o test` → 206 个用例（core 201 + web 5）。

## 用法示例

```yaml
- id: wagg
  type: window.aggregate
  config:
    keyBy: [user_id]
    window: {type: tumbling, size: 100ms}
    aggregates:
      - {fn: COLLECT_SET, column: tag, alias: tags}   # 窗口内去重收集
      - {fn: SUM, column: amount, alias: total}
```

## 注意

- 收集的状态随窗口一起清理；封顶（65536）照常兜底。
- 迟到行进 `lateTo` 侧输出的口径不受收集函数影响（窗口已触发才收的迟到行不补数组）。
