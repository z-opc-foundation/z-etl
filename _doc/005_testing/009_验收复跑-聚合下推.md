# 验收复跑 · 聚合下推（DAG 层）

> 卡面纪律：**错了就是静默丢数据** ⇒ 下推必须用户显式声明 + 下游列守卫逐条设卡。

---

## 1. 规则与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | 下推**由用户在源节点显式声明**（`pushdown.groupBy` + `pushdown.aggregates`） | 引擎不猜「这个聚合能不能下推」；口径像 `where` 一样写死在源上 |
| 2 | 引擎侧 `aggregate` 的 `keyBy` / `aggregates` 必须与源声明**逐条一致**（分组列集合 + fn/column/alias） | 不一致 ⇒ 源已按分组聚合过，引擎再聚合是对聚合结果再聚合，可能是用户有意为之 ⇒ 保留引擎侧计算 + 备注提示 |
| 3 | **下游列守卫**：下游用到的列必须都在「分组列 + 聚合别名」里 | 引擎侧 aggregate 输出「整行 + 别名」，下推后源只输出「分组列 + 别名」⇒ 下游引用别的列会拿到空值 |
| 4 | 精确列名（`field.mapping` 的 source、汇的 `columns`/`idempotencyKey`、`keyBy`、聚合列、类型归一列）不在输出列集 ⇒ 不摘 | 列名是精确的，判错就是错 |
| 5 | 表达式里的标识符按**源表列清单**判定；清单拿不到 ⇒ 不摘 | 运行时用 JDBC 元数据取（`JdbcTableSchemaResolver`）；拿不到就按「不知道」保守处理，不猜关键字 |
| 6 | 整行脚本（`script(mode=row)` / `mode=column`）/ `join` ⇒ 引用不可知 ⇒ 不摘 | 脚本可以读整行 ⇒ 丢了哪列不可知 |
| 7 | 聚合下推与 `eventTimeColumn` **互斥** | 聚合结果是分组口径，水位过滤对它没有意义 ⇒ 声明了就报错（跑之前拦下） |
| 8 | 聚合表达式**不是自由 SQL** | 函数名白名单（`SUM/COUNT/AVG/MIN/MAX`）+ 列名标识符白名单；聚合表达式无法参数绑定，自由文本即注入面 |

口径变化（备注里写清楚）：摘掉 aggregate 节点后，结果从「流式滚动累计（每条输入发一次）」
变成「SQL GROUP BY（每组一行）」。

## 2. 运行时即优化

- 执行器跑之前先优化一遍（**深拷贝后改写**，不动调用方的声明）；
- 优化器拿 **JDBC 元数据**里的源表列清单来判「下游引用的列还在不在」（`JdbcTableSchemaResolver`）；
- 优化备注（每条规则做了什么 / 为什么没做）写进运行结果（`result.getNotes()`）。

## 3. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=AggregatePushdownTest
```

预期：`Tests run: 7, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `aggregateIsPushedToSource` | 下推生效：aggregate 节点被摘掉；结果与源库 `GROUP BY` **逐字段一致**；读到的行数 = 分组数（3）而不是明细数（10） |
| `keepsAggregateWithoutPushdown` | 源没声明下推 ⇒ 不摘 |
| `keepsAggregateWhenMismatch` | 源声明与节点不一致 ⇒ 不摘 + 备注提示 |
| `keepsAggregateWhenDownstreamNeedsLostColumn` | 下游表达式用了真实列 `amount`（下推结果里没有）⇒ 不摘 + 备注点名缺哪列 |
| `keepsAggregateWhenDownstreamIsOpaque` | 下游是整行脚本（引用不可知）⇒ 不摘 |
| `pushesWhenDownstreamOnlyUsesAvailableColumns` | 下游只用得到的列 ⇒ 照常摘 |
| `rejectsIllegalPushdown` | 非法下推声明在跑之前被拦下（函数白名单 / 列白名单 / 与水位互斥） |

## 4. 与线性层的关系

线性作业层（`source.pushdown`）的聚合下推本轮之前就有；本轮补的是 **DAG 层**：
`jdbc.source` 节点的 `config.pushdown` → 源库 `GROUP BY` → 引擎不再重复算，
两层的下推声明口径一致（函数白名单 + 标识符白名单 + 互斥水位）。
