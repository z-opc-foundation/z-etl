# 验收复跑 · 调度登记（cron）

> 口径：**z-etl 只登记，不起常驻定时线程**。
> 真正的定时器由宿主驱动（z-ops 定时任务 / k8s CronJob 调 `POST /api/etl/pipelines/{name}/run`），
> ETL 进程不背调度职责，也不用管自己的存活。

---

## 1. 口径

| 项 | 口径 |
|---|---|
| 表达式 | 5 段 cron（分 时 日 月 周）；支持 `*`、`*`/`n`、`a-b`、`a-b`/`n`、`a,b,c`、单值 |
| 日 / 周 | 都写了且都不是 `*` 时取**并**（cron 惯例） |
| 落点 | `etl_pipeline_schedule`（pipeline_name 主键 + cron_expression + enabled + last_triggered_at） |
| 可观测 | 登记对象带**下一次触发时间**（本仓自算，供宿主对表与排障） |
| 记账 | 每次成功触发后更新「上次触发时间」（`touch`） |
| 幂等 | 同一流水线重复登记即覆盖（UPSERT） |

REST 面：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/etl/pipelines/{name}/schedule` | 登记调度（body = cron 表达式，`?enabled=true/false`） |
| GET | `/api/etl/pipelines/{name}/schedule` | 调度登记（含下一次触发时间） |
| DELETE | `/api/etl/pipelines/{name}/schedule` | 取消调度 |
| GET | `/api/etl/pipelines/schedules` | 全部调度登记 |

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=CronExpressionTest+PipelineScheduleTest
```

预期：`Tests run: 10, Failures: 0, Errors: 0`（cron 6 + 调度 4）

| 用例 | 覆盖 |
|---|---|
| `CronExpressionTest#everyFiveMinutes` | `*/5` 落在 5 分钟刻度 |
| `CronExpressionTest#dailyAtThree` | 每天 03:00：当天没到就当天，过了就次日 |
| `CronExpressionTest#monthlyAndWeekly` | 每月 1 号 00:00；周一 09:00 |
| `CronExpressionTest#listsAndRanges` | `0,30 9-17` 列表 + 区间 |
| `CronExpressionTest#rejectsInvalidExpressions` | 段数不对 / 越界 / 非数字 / 空 ⇒ 报错 |
| `CronExpressionTest#nextFireMovesForward` | 连续两次触发时间严格递增（不卡在同一分钟） |
| `PipelineScheduleTest#scheduleIsVisible` | 登记后能看到 cron 与下一次触发时间 |
| `PipelineScheduleTest#triggerRecordsLastTriggeredAt` | 触发一次 ⇒ 记下上次触发时间 |
| `PipelineScheduleTest#unscheduleRemoves` | 取消调度 ⇒ 登记消失 |
| `PipelineScheduleTest#rejectsBadScheduleInput` | 未登记的流水线 / 非法 cron ⇒ 报错 |

> web 层口径见 `EtlPipelineServiceTest#scheduleIsVisibleAndCancelable`（登记 / 查 / 取消）。
