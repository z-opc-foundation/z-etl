# 验收复跑 · 异步映射（`async.map`）

> 卡面：**异步 IO（Flink AsyncFunction 口径）** —— 每行异步外呼 HTTP 补列：请求并发在途、容量背压、有序/乱序产出、流结束 flush 收尾。「按行查行情 / 查用户档案」不再把单线程执行器卡成串行。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | **容量背压**：在途请求数到 `capacity`（缺省 100）就不再拉新行，阻塞在最早在途上等一个完成 | Flink async capacity 同口径；下游不会被在途请求冲垮内存 |
| 2 | **产出顺序**：`outputMode: ordered`（缺省）严格按行到达序发出（乱序完成的等前面的）；`unordered` 完成即发（吞吐优先） | Flink AsyncFunction 的两种 outputMode |
| 3 | **流结束刷余**：源跑完后执行器按拓扑序调 `flush(Output)`（Operator 接口新默认方法，Flink endOfInput 口径），在途的全部发出后才 close | 单线程执行器没有别的产出时机；`flush` 是通用钩子，其它算子也能用 |
| 4 | **url 模板**：`{列名}` 从行取值（URL 编码）；缺列直接报错点名 —— 模板列会被**列下推**认作上游必须供给的列 | 模板列被上游裁掉 = 100% 派发失败，下推必须知道 |
| 5 | **响应提取**：`fields: [{target, source}]`，source 是响应 JSON 的点路径（`data.balance`；数组下标 `items.0`）；source 缺省 = target（顶层键） | 补的列来自外部接口，路径语义与文件源 `itemPath` 一致 |
| 6 | **失败语义**：缺省 fail fast（抛出点名）；`onError: skip` 丢行并计数 `failed-skipped` | 不静默装成功；skip 给脏接口一个活路 |
| 7 | **信任边界**：`allowedHosts` 声明后只允许这些主机（SSRF 收口）；缺 `url` 校验期报错 | 与 http.source 同一套白名单口径 |
| 8 | 无状态变换（Kind.TRANSFORM）⇒ 不进状态快照；超时靠 HttpRequest 的 connect/read timeout | 异步等待不占键控状态；失败重试留给上层 `retry` 机制 |

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=AsyncMapOperatorTest
```

预期：`Tests run: 7, Failures: 0, Errors: 0`（本地 `com.sun.net.httpserver`，不连外网）

| 用例 | 覆盖 |
|---|---|
| `enrichSingleRowViaFlush` | 单行：产出走的是流结束 `flush`（没有下一条 processElement 可搭车）；`balance` 从响应点路径提取、原行字段保留、`enriched` 计数 |
| `orderedKeepsArrivalOrder` | 服务器对早到的行故意慢 300ms ⇒ ordered 产出仍按行到达序 |
| `inFlightParallelism` | 3 行各慢 300ms + `capacity: 3` ⇒ 墙钟 < 800ms（串行 ~900ms），证明确实并发在途 |
| `capacityBackpressure` | `capacity: 1` 也能全部产出（只是没有并发重叠） |
| `errorSkipped` | 全 500 + `onError: skip` ⇒ 全丢 + `failed-skipped` 计数 |
| `errorFailsByDefault` | 缺省 fail fast：抛出点名「外呼失败」 |
| `rejectsBrokenConfigs` | 缺 `url` 校验期报错；`allowedHosts` 白名单外拒绝（执行器包成 IllegalStateException，根因消息点名「拒绝访问」） |

## 3. 用法示例

```yaml
- id: enrich
  type: async.map
  config:
    url: "http://user-api/profile/{user_id}"
    fields:
      - {target: balance, source: data.balance}
    capacity: 100
    timeoutMs: 3000
    allowedHosts: [user-api]
```

⚠️ 实测注意：执行器会把算子抛出的异常包成 `IllegalStateException`（「派发失败」根因链），断言异常类型时看根因消息。
