# 验收复跑 · 维表关联（`dim.join`）与异名键关联

> 卡面：**维表要能热更新，键名要能不一样** —— 右流即维表（同键替换 + TTL 过期），join 家族左右键列允许不同名。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | `dim.join`：右流（维表流）同键**替换**旧条目（热更新），维表行只进状态**不下传** | Flink broadcast-state 关维表的口径；维表行不是要输出的数据 |
| 2 | `ttl` 声明后：事件时间早于「水位 − ttl」的维表条目在水位推进时清掉；没声明 = 永不过期 | 维表不再续发 ⇒ 过了保鲜期宁可断掉，不拿陈年旧值硬拼 |
| 3 | 声明 `ttl` 时维表行**必须带事件时间**，否则丢弃并计数（`no-event-time-dropped`） | 没版本时间就没法判过期，不静默装新 |
| 4 | `select` 投影：只有声明的维表列进状态、拼到主流；不声明 = 全列 | 维表通常很宽，主流只需要几列 |
| 5 | **异名键关联**：join 家族（`join` / `interval.join` / `dim.join`）的 `leftKey`/`rightKey` 列名允许不同（`city_id` 对 `id`），按「第 i 个键列的值相等」关联（`Keys.computeValues`，键里不含列名） | 维表主键几乎不可能与主流外键同名；旧 `Keys.compute` 把列名编进键 ⇒ 异名必失配 |
| 6 | `joinType`：inner（未命中不发）/ left（未命中也发，维表投影列补 null 后缀列） | 与 `join` 同款 |
| 7 | 活跃键清单挂在哨兵键 `\u0000dim-join-active-keys` 下（水位的全局清理靠它遍历）；与 `interval.join` 的哨兵键不同名 | 状态按算子隔离，但哨兵名不同更稳 |
| 8 | 状态条目可序列化 ⇒ 能进检查点（断点续传口径与其它有状态算子一致） | — |

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=DimJoinOperatorTest
```

预期：`Tests run: 5, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `joinsWithProjection` | 异名键（`city_id` ↔ `id`）关联 + `select: [city_name]` 投影（province 不拼）+ `dim-updated`/`matched` 计数 |
| `hotUpdateAndTtlExpiry` | 同键维表重发**替换**旧值（第一条主流拼旧值、第二条拼新值）；水位过后旧条目过期清掉并计数 |
| `leftOuterEmitsUnmatched` | 主流没命中也发，且不拼维表值（未命中无 null 后缀列，因为 `rightColumns` 只记真实进过状态的列） |
| `dimRowWithoutEventTimeDropped` | 声明 ttl 但维表行没事件时间 ⇒ 丢弃并计数 |
| `requiresKeys` | 缺 `leftKey`/`rightKey` ⇒ 跑之前报错并点名 |

⚠️ 实测注意：执行器按源声明序轮询拉取 ⇒ 维表源要**声明在主流之前**，维表条目才先于探测到达（区间连接两侧都缓存所以不挑顺序，维表关联的探测语义挑）。

⚠️ 顺带修复（口径变化）：`join` / `interval.join` 的关联键从「列名=值」换成「纯值按位置」——旧状态快照里的键格式不兼容（升级后第一次跑等同重建状态，水位口径不受影响）。
