# 验收复跑 · 失败重试与退避

> 口径：**不声明 `retry` ⇒ 行为与从前完全一致**（异常原样抛出，类型与信息都不变）；
> 声明了才启用「整体重跑 + 指数退避」。
>
> 全部验收在本地 HTTP 接口上做「前 N 次失败」的可控故障源，不连外网。

---

## 1. 口径

| 项 | 口径 |
|---|---|
| `maxAttempts` | **总尝试次数**（含第一次）；默认 1 = 不重试 |
| `backoffMs` | 首次重试前的等待；之后按 `multiplier` 指数退避 |
| `maxBackoffMs` | 退避上限（默认 60s） |
| 重试粒度 | **整体重跑**：水位只在本页写成功后推进 ⇒ 重跑从上次成功页接力 |
| 幂等性 | 目标侧是幂等 upsert ⇒ 重搬已落的行无副作用（不重不漏） |
| 失败终局 | 抛「连续 N 次失败」并带上最后一次的原始原因（cause 链保留） |
| 履历 | 成功的重试在履历里注明「第 N 次尝试成功」 |

声明位置：

- 线性作业：job 描述顶层 `retry: {...}`
- 流水线：流水线声明顶层 `retry: {...}`

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=RetryPolicyTest
```

预期：`Tests run: 3, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `linearJobRetriesUntilSuccess` | 作业级：前两次 HTTP 500、第三次 200 ⇒ 自动重试跑通；履历注明「第 3 次尝试成功」 |
| `pipelineRetriesUntilSuccess` | 流水线级：同上（`PipelineEngine`） |
| `exhaustedRetriesReportAttempts` | 重试用尽 ⇒ 报错含「连续 2 次失败」；且**只尝试 2 次**（不多试） |

> 回归护栏：`SandboxGuardTest`（沙箱超时 / LUA 硬拒绝）验证了「不声明 retry ⇒ 异常原样抛出」这条口径。
