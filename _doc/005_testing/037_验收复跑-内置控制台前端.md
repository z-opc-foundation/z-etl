# 037 验收复跑 —— 内置控制台前端

- 日期：2026-11-21
- 模块：z-etl-web
- 形态：零依赖单文件 SPA（`z-etl-web/src/main/resources/static/index.html`，vanilla JS + fetch，打进 jar，无 Node 构建）

## 口径

- 同源调 `/api/etl/pipelines` 与 `/api/etl/jobs`，无跨域问题；
- 登记用 **Content-Type: text/plain** 传 yml/JSON 原文（与 REST 口径一致）；
- 运行结果渲染 `nodeMetrics`（records-in/out + 其余计数）、水位、notes；
- 保存点导出纯读展示，灌回手工粘贴（可带 targetName）；
- 调度 cron 是 **5 段**（分 时 日 月 周，无秒、无 `?`）。

## 复跑（浏览器实测）

1. 开 `http://localhost:8092/` → 控制台加载，流水线列表出已登记管道；
2. 点管道 → 定义 / 计划解释（拓扑序文本）正常渲染；
3. 点「运行」→ 3 进 2 出、`duplicates=1`、节点指标表齐全；
4. 调度登记 `0 3 * * *` 成功（下次触发时间回显）；调度总览表格正确；取消调度成功；
5. 作业 tab 空列表正常显示「（空）」。
