# 验收复跑 · XML 连接器（`file.xml.source` / `file.xml.sink`）

> 卡面：**XML 也要进出自由** —— 零外部依赖（JDK 自带 StAX），sink 流式写、source 流式读。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | 解析 / 写出全走 JDK 自带 `javax.xml.stream`（StAX），**不引第三方依赖** | maven central 受限；xlsx 已开先例 |
| 2 | sink 用 `XMLStreamWriter` 流式写：标量列 → 子元素文本（转义交给 writer）、null → 空元素、Map/List 列 → 跳过 | XML 扁平行不装嵌套结构 |
| 3 | source 用路径栈流式读：`recordPath`（从根元素起算的点路径，如 `data.item`）定位记录元素；**不声明**就取根下第一个子元素（流中首次遇到时定位，不回头重读） | 大文件不必整读进内存 |
| 4 | 记录的属性 → 列（列名加前缀，默认 `@`）；嵌套子元素 → 递归成 Map；同名子元素重复出现 → 合成 List；空元素 → null | 覆盖外来 XML 的常见形状 |
| 5 | 列类型：声明 `columnTypes` 优先，未声明走推断（数字 / 布尔 / Timestamp 文本自动还原） | 与 CSV / JSON 源同一套 `ColumnTypes` 口径 |
| 6 | `columns` 投影 + `limit` 截断 | 与 JSON 源同款 |
| 7 | sink 覆盖写（不追加）；`rootName`（默认 `rows`）/ `recordName`（默认 `row`）/ `declaration`（默认 true）可配 | — |
| 8 | 线性作业层 `source.type: file.xml` / `target.type: file.xml` 直接落到同一实现 | 连接器矩阵口径：不另写一套 |

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=FileXmlConnectorTest
```

预期：`Tests run: 4, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `writesAndRoundTrips` | sink 写（含特殊字符转义 `A&amp;B&lt;C&gt;`）→ source 读回：数字推断成 LONG、时间文本推断还原成 Timestamp、特殊字符原样往返 |
| `readsForeignXmlShapes` | 外来 XML：`recordPath: data.item` 定位、属性成 `@id`/`@level` 列、嵌套 `<detail>` 成 Map、重复 `<tag>` 合成 List、空元素成 null |
| `projectionAndLimit` | `columns: [id]` 投影丢掉 name、`limit: 3` 截断 10 行 |
| `validationAndAliases` | 缺 `path` 跑前报错并点名；类型别名 `xml.source`/`file.xml`/`xml.sink`/`file.xml.out` 双向可解析 |

## 3. 用法示例

```yaml
nodes:
  - id: src
    type: file.xml.source
    config:
      path: /data/orders.xml
      recordPath: data.item          # 不写就取根下第一个子元素
      columnTypes: {amount: BIGDECIMAL}
  - id: out
    type: file.xml.sink
    config:
      path: /data/out.xml
      rootName: rows
      recordName: row
```
