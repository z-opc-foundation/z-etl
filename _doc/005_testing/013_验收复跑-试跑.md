# 验收复跑 · 试跑（`dryRun`）

> 卡面：**试跑不能留下任何痕迹** —— 不落目标表、不落水位、不落状态快照、不落履历。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | 汇**只计数不落地**（`DryRunSink` 替换真实汇） | 不会把试验数据写进目标表 |
| 2 | `recordsWritten` = 「试跑下来**会写**多少行」 | 量具语义：这个数字就是正式跑的预期产出 |
| 3 | **不读不写水位** | 试跑不能当增量起点；试跑跑过的不算「已搬运」 |
| 4 | **不读不写状态快照** | 试跑不算正式运行，键控状态不留痕 |
| 5 | 不落履历（`engine.dryRun` 不走 `saveRun`） | 履历是正式运行的历史 |
| 6 | 最多处理 `sampleRows` 行（源不足就跑完为止） | 大表试跑不必全扫 |
| 7 | 试跑**从全量跑**（不读水位） | 可预测：「第一次跑会是什么样」；配合 sampleRows 兜底 |

## 2. 入口

| 入口 | 用法 |
|---|---|
| Web | `POST /api/etl/pipelines/{name}/dry-run?rows=100`（body 可选 = 运行参数） |
| 代码 | `engine.dryRun(name, params, sampleRows)` / `executor.dryRun(spec, sampleRows)` |

## 3. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=PipelineDryRunTest
```

预期：`Tests run: 3, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `stopsAfterSampleRowsWithoutWriting` | 试跑 3 行：读到 3 行、会写 3 行，目标表 0 行、水位没落、状态快照没落 |
| `fewerRowsThanSampleRunsToCompletion` | 行数不足 sampleRows ⇒ 跑完为止（也不落地） |
| `dryRunDoesNotTouchRealState` | 正式跑之后再试跑：水位纹丝不动、目标表不被写入（全量试跑 + sampleRows 兜底） |
