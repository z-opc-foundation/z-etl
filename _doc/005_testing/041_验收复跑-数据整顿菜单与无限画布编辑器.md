# 041 验收复跑 — 数据整顿菜单重排 + 无限画布模板编辑器 + 主壳接入

日期：2026-11-25　分支：main

## 交付内容

1. **控制台菜单逻辑重排**（CEO 口径「插件 / 数据源 / 输出源 / 中间是模板 / 调度 / 作业」）：
   左树改为五组——数据源（源算子目录）、输出源（汇算子目录）、模板（列表 + ＋新增模板 + 原文直登）、调度、作业；
   五页签 hash 路由 `#sources/#sinks/#templates/#schedules/#jobs`。
2. **算子目录 API**：`GET /api/etl/operators`（`EtlOperatorController`），返回 51 个算子的
   `{id, kind, desc}`，画布调色盘与目录页共用这一份数据真源。
3. **无限画布模板编辑器**（零依赖自研，玩法对齐审批流编辑器）：算子调色盘四类分栏、点入画布
   （按画布宽度网格排布，窄视口自动换行）、节点拖拽、以鼠标为锚缩放 0.3–2×、端口拖线成边
   （贝塞尔 + 箭头，点边删除）、右侧 config 面板按算子预填示例、保存即登记、重进回载分层布局。
4. **主壳接入**：z-team 系统面 `SystemWorkbench` 新增「数据整顿」组（五子菜单 → `/etl/:view`），
   `SystemShell` 挂 `EtlWorkbench`（iframe 挂同源 `/etl/index.html#<view>`，照知识中台先例）；
   主壳 vite 与 e2e/system-mode 台子各补 `^/etl/` 剥前缀代理到 :8092；
   控制台按 `location.pathname` 前缀 `/etl/` 自动给 API 调用补同段前缀（独立跑不受影响）。

## 本波修出的两个画布真 bug

1. **新增节点全叠画布中心**：`edAdd` 恒用画布中心落位 → 改为按画布宽度网格错开（`cols` 列自动换行）。
2. **拖线连线必失败**：mouseup 用 `elementFromPoint` 找落点，被连线预览的箭头 marker / 右侧配置面板
   （节点拖到可视区外时）挡住 → 判定前临时隐藏 SVG；配合网格落位根治。

## 部署注意事项

- z-etl 本地库：专用容器 `z-etl-mysql`（host 13307，库 `etl`），起服务注入
  `ZETL_DB_HOST/PORT/NAME/USERNAME/PASSWORD`（凭据不落盘）；`EtlSchema` 全 `CREATE TABLE IF NOT EXISTS` 自动建表。
- 主壳生产化：`/etl/` 前缀路由需要在 aio 前端 nginx（或 Traefik）补一条剥前缀反代到 z-etl 服务，
  z-team 侧改动随下次组件发版进主壳（本轮只提交源码，未发版）。
- 判绿以 `mvn clean test` 为准（并行会话遗留 surefire 报告会假红，见 040）。
