# 验收复跑 · 窗口迟到侧输出（`lateTo`）

> 卡面：**被丢的迟到行有去处** —— 窗口触发后超窗来的行不再只丢个计数：声明 `lateTo` 后原样走侧输出给旁路节点（Flink side output 口径，与 filter 的 `rejectedTo` 同一套标签路由）。

---

## 1. 口径与边界

| # | 边界 | 为什么 |
|---|---|---|
| 1 | **丢弃判定不变**：窗口已触发（`fired`）且水位 > 窗口尾 + `allowedLateness` 才算迟到丢弃；`allowedLateness` 内的迟到照旧重算重发（`late-refired`），不进侧输出 | 侧输出只接「真丢了」的行，正常重发语义不动 |
| 2 | **原样转发**：侧输出的是**原始行**（不是聚合后的行），标签 id = `lateTo` 指向的节点 id | 迟到审计 / 落死信表要的是原始数据 |
| 3 | **计数保留**：`late-dropped` 照旧累加，`side-output-sent` 另计 | 观测口径不回退 |
| 4 | **不声明 `lateTo` 行为不变**：只丢计数 | 向后兼容 |
| 5 | `lateTo` 指向不存在的节点 ⇒ 开跑前报错点名（执行器旁路检查，与 `rejectedTo` 同一套） | 不等到运行时静默丢 |
| 6 | **列下推**：侧输出目标需要的列并入窗口算子的上游需求（被丢的行要全须全尾地到旁路） | 上游裁掉列 = 旁路收到残行 |
| 7 | 执行器派发期异常包 `IllegalStateException`（根因链点名真实原因） | 断言时看根因消息 |

## 2. 复跑命令

```bash
cd z-etl
JAVA_HOME=$(/usr/libexec/java_home -v 17) mvn -o test -Dtest=WindowLateSideOutputTest
```

预期：`Tests run: 4, Failures: 0, Errors: 0`

| 用例 | 覆盖 |
|---|---|
| `lateRowGoesToSideOutput` | t=120 对着已触发的 `[100,200)` 窗口来 ⇒ 原行进 `dead` 节点；主流两窗口照常；`late-dropped` = 1、`side-output-sent` = 1 |
| `withoutLateToJustDrops` | 不声明 `lateTo` ⇒ `dead` 节点空、只丢计数（行为不变） |
| `withinLatenessRefires` | `allowedLateness: 1s` ⇒ t=120 的行重算重发（`late-refired` = 1），不进侧输出、不丢 |
| `lateToTargetMustExist` | `lateTo: ghost` ⇒ 跑之前报错点名 |

## 3. 用法示例

```yaml
- id: wagg
  type: window.aggregate
  config:
    keyBy: [user_id]
    window: {type: tumbling, size: 5m}
    allowedLateness: 1m
    lateTo: dead-letters          # 超窗的迟到行落死信
    aggregates:
      - {fn: SUM, column: amount, alias: total}
```

⚠️ 实测注意：inline 源声明 `columnTypes: {t: LONG}` 后行值是 `Long`（不是 `Integer`），断言用 `Long.valueOf`。
